# Support

- Setup problem or reproducible bug: open a bug report.
- Feature idea: open a feature request and describe the user workflow.
- Security issue: follow [SECURITY.md](SECURITY.md); do not file it publicly.
- Provider outage, quota, billing, or login issue: check the provider's status and
  documentation first because Coder Council does not own provider accounts.

Before asking for help, run `coder-council doctor` and include its redacted output,
your operating system, Node version, VS Code version, and Coder Council version. Never
paste API keys, OAuth tokens, browser cookies, or `.council` run contents containing
private project information.
