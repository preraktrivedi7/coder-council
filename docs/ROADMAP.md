# Roadmap

Coder Council is usable today as a terminal orchestrator and Codex-compatible VS Code
workspace. The roadmap focuses on adoption without weakening the safety model.

## Next

- Publish signed VS Code Marketplace and Open VSX releases.
- Add run timelines that expose candidate evidence and disagreements clearly.
- Make local-model discovery and model sizing more automatic across platforms.
- Add opt-in provider adapters through a documented seat interface.

## Later

- Portable, redacted run export for bug reports and team review.
- Workspace prompt templates and reusable Council policies.
- Accessibility and localization passes for the complete VS Code workspace.
- Reproducible evaluation dashboards based on human outcomes, not model votes.

## Non-goals

- Account rotation, quota bypass, browser-cookie scraping, or credential sharing.
- Hidden paid fallbacks.
- Automatically committing or pushing model-written code.
- Persisting private chain-of-thought.

Open a feature request if you want to help shape or implement an item.
